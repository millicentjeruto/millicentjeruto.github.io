# Millicent Jeruto Portfolio

A clean, responsive, multi-page portfolio for 3D Modelling, Illustration and Infographics.

## Pages
- Home
- About
- 3D Modelling
- Illustration
- Infographics
- Contact

## Add your work
Put your images in the `assets` folder using these filenames:
- `profile.jpg`
- `3d-01.jpg` through `3d-10.jpg`
- `illustration-01.jpg` through `illustration-10.jpg`
- `infographic-01.jpg` through `infographic-10.jpg`

Then replace the placeholder blocks with `<img>` tags if desired.

## Publish free with GitHub Pages
1. Create a GitHub account.
2. Create a new repository named `yourusername.github.io` (replace `yourusername` with your GitHub username).
3. Upload all files and the `assets` folder.
4. Go to Settings → Pages.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. Your site will appear at `https://yourusername.github.io/`.

## Customize
- Replace the email in `contact.html`.
- Replace the LinkedIn `#` with the real profile URL.
- Edit project titles and descriptions.
- Change colors/fonts in `style.css`.
